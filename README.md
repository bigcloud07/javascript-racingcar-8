# 2주차 미션 - 자동차 경주 🚘

# 🧩 프로그램 진행 프로세스

## 입력

1. 사용자에게 자동차 이름들을 입력받는다.
    1. `,` 를 기준으로 자동차 이름들을 parsing 한다.
    2. 입력받은 자동차 이름 문자열의 앞, 뒤 공백을 제거한다.
        1. 자동차 이름이 입력되지 않았는지 검사한다.
        2. 자동차 이름이 영문으로만 구성되었는지 검사한다.
        3. 자동차 이름의 글자 수가 5자가 넘었는지 검사한다.
        4. 자동차 이름 사이에 공백이 있는지 검사한다. (ex: a b)
        5. 자동차 이름이 하나만 입력되었는지 검사한다.
        6. 중복된 자동차 이름이 있는지 검사한다.
2. 자동차 이름들을 key로 하고 `‘’` (빈 문자열)을 value로 하는 `cars`객체를 생성한다.
3. 진행할 라운드 수(전진을 시도할 횟수)를 입력받는다.
    1. 입력받은 라운드 수 문자열의 앞, 뒤 공백을 제거한다.
        1. 라운드 수가 입력되었는지 검사한다.
        2. 입력받은 라운드 숫자 사이에 공백이 있는지 검사한다. (ex: 1 2)
    2. 라운드 숫자 문자열을 `Number` 함수로 숫자로 형변환 한다.
        1. 숫자인지 검사한다.
        2. 자연수(양의 정수)를 입력했는지 검사한다.
## 게임 진행

- 입력받은 라운드 수만큼 다음의 내용을 반복하여 진행한다.
    1. 각 자동차에 난수를 발생시키는 함수를 이용하여 난수를 부여한다.
    2. 4이상의 숫자가 나오면, 전진하고 `cars` 에 해당 자동차 프로퍼티에 `-` 라는 문자열을 추가한다.
    3. `cars` 객체에 저장된 각 차량의 이름들과 저장된 전진 상태를 출력한다.

## 결과 출력

1. 마지막 라운드의 기준으로 `-` 문자열의 개수를 확인한다.
2. `-` 문자열의 개수가 제일 많은 자동차를 확인하고 우승자를 선정한다.
3. 우승자를 출력한다.

# 🚀 구현 기능 목록
## 1. 경주할 자동차 입력 기능 (✅)
- 사용자로부터 경주할 N대의 자동차 이름을 입력을 받는다.
- 쉼표(`,`)를 기준으로 자동차의 이름을 구분한다.
- 자동차의 이름은 5자로 제한한다.
## 2. 시행 횟수 입력 기능 (✅)
- 사용자로부터 각 자동차가 전진을 시도할 횟수를 입력 받는다.
## 3. 자동차 전진 기능 (✅)
- 경주가 시작되면 각 자동차들은 0~9 사이의 랜덤한 하나의 숫자를 부여받는다.
- 부여받은 숫자가 4 이상이면 그 자동차는 전진한다.
- 전진할 때마다 자동차 이름 옆에 문자열 `-`가 추가된다.
## 4. 우승자 출력 기능 (✅)
- 가장 전진을 많이 한 자동차의 이름을 출력한다.
- 우승자가 여러 명일 경우 쉼표(`,`)로 구분하여 모두 출력한다.
## 5. 예외 처리 (✅)
>사용자가 잘못된 값을 입력할 경우, `[ERROR]`로 시작하는 메시지와 함께 Error를 발생시킨 후 애플리케이션이 종료됩니다.
### 🚗 자동차 이름 관련 예외
- 이름을 **입력하지 않은 경우**
- 이름을 **하나만 입력한 경우**
- 이름이 **5글자 이상인 경우**
- 이름에 **공백이 포함된 경우**
- 자동차 이름이 **중복된 경우**
- 자동차 이름이 **영문자가 아닌 경우**

### 🔢 시행 횟수 입력 관련 예외
- 시행 횟수를 **입력하지 않은 경우**
- 시행 횟수가 **숫자가 아닌 값인 경우**
- 시행 횟수가 **자연수가 아닌 경우**
- 시행 횟수 **사이에 공백이 있는 경우**
